### Added

- The hosted ledger migration refreshes an existing hosted copy only when the
  command names the frozen source digest (`--expect-source`) and the hosted digest
  it replaces (`--replaces`) for one `--slug`. The hosted service refuses a refresh
  whose hosted copy changed since that digest, archives the displaced copy with its
  history, registries and media under the ledger's displaced folder, keeps the
  ledger token, and leaves an unguarded import refusing any diverged copy.
