### Added

- `SWARM_URL` points the ledger CLI, the swarm tick and the ledger hooks at a hosted Swarm ledger. With it set they never start or restart a local ledger server.
- `SWARM_ACCESS_CLIENT_ID` and `SWARM_ACCESS_CLIENT_SECRET` add the Cloudflare service token headers to every ledger request and health probe.
- A client holding `SWARM_SECRET` derives its own agent token, and the swarm tick hands each agent it spawns its own token in place of the secret.
